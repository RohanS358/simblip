## Measured (SYNTHETIC generated hands only — not real handwriting)
150 whole circuits: **68 % drawn circuits read back exactly**; parts found 96 %,
class correct 96 %; ~1.1 taps to fix per circuit. First run was 19 %.
Failures: 22 op-amp circuits, 18 missed/extra parts, 4 wrong class, 4 wiring only.
Tolerances (`tolPinK` 0.4, `tolJoinK` 0.12) were tuned on this same synthetic set,
so the number is optimistic.
